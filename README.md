# ✍️ AIライティングツール

Python + Streamlit + Gemini API で作った、個人用のオールインワン AI ライティングツールです。

## 搭載ツール

| ツール | 内容 |
|---|---|
| 📝 ブログ記事作成 | テーマ・読者・キーワード・文字数から見出し付き記事 + メタディスクリプション |
| ✉️ メール返信作成 | 受信メールを貼り付けて返信文（件名つき）を作成 |
| 📨 新規メール作成 | 用件から新しいメール文面を作成 |
| 📋 文章要約 | 箇条書き / 3行 / レポート / TL;DR など形式を選んで要約 |
| 🔍 文章校正 | 修正後の全文 + 修正点の一覧表 |
| 🔄 リライト・トーン変換 | 意味を保ったままトーンや長さを変更 |
| 🌐 翻訳 | 多言語翻訳（意訳 / 直訳 / ビジネス向けなど） |
| 📣 SNS投稿作成 | X・Instagram など媒体に合わせた投稿を複数パターン |
| 💡 タイトル・キャッチコピー | タイトル / コピー / 件名などの案を量産 + おすすめ案 |
| 🗂️ 構成案作成 | 記事・プレゼン・台本などの見出し構成 |
| 🧠 アイデア出し | ネタ・企画のブレインストーミング |
| ✍️ メモから文章化 | 箇条書きメモを日報・議事録・文章に |
| 🪄 フリー指示 | 自由なプロンプトで依頼 |

共通機能: ストリーミング表示 / 🔧 生成結果への追加修正指示 / コピー・Markdown ダウンロード / 文字数カウント / 🕘 生成履歴（セッション内）/ temperature の切替（モデルは `.env` の `GEMINI_MODEL` で指定）

## セットアップ

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt

copy .env.example .env   # GEMINI_API_KEY を書き込む
streamlit run app.py
```

APIキーは [Google AI Studio](https://aistudio.google.com/apikey) で取得できます。`.env` を作らずに、画面サイドバーの「⚙️ 設定」から入力することもできます。

## ファイル構成

```
app.py            # Streamlit の画面
tools.py          # 各ツールの定義（入力欄とプロンプト）
gemini_client.py  # Gemini API 呼び出し
```

## ツールの追加方法

`tools.py` にプロンプトを組み立てる関数を書き、`TOOLS` リストに `Tool(...)` を追加するだけで、サイドバーと入力フォームが自動で生成されます。
